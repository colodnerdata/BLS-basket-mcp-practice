# Sample data

This folder contains small, deterministic examples for local development and
offline testing. The files are intentionally concise and synthetic so they can be
used without a live BLS API key.

## Files

- `catalogue_sample.json`: example series metadata for catalogue search and
  validation.
- `basket_sample.json`: example weighted basket specification that matches the
  project's escalation models.
- `observations_sample.json`: small observation history for a few synthetic
  series.

These files are intended as examples only; they are not production BLS data and
should not be used for business decisions.
